  AGRILEASE - QUICK START GUIDE
═══════════════════════════════════════════════════════════

SETUP (3 Steps):
═══════════════════════════════════════════════════════════

1. Import Database
   mysql -u root -p < agrilease_complete.sql

2. Edit includes/config.php
   - Set your database password

3. Open Browser
   http://localhost/agrilease/


FEATURES:
═══════════════════════════════════════════════════════════

✅ Auto-generate receipts (with GST)
✅ Confirm bookings (owner)
✅ Cancel bookings (renter)
✅ Prevent double bookings
✅ Print/Download receipts


HOW TO USE:
═══════════════════════════════════════════════════════════

AS RENTER:
1. Browse products
2. Book equipment
3. Wait for owner confirmation
4. View receipt
5. Cancel if needed

AS OWNER:
1. Add products
2. Receive booking requests
3. Confirm or decline
4. View receipt
5. Mark as complete


KEY PAGES:
═══════════════════════════════════════════════════════════

/products.php           - Browse equipment
/manage_bookings.php    - Confirm/manage bookings
/receipt.php?id=X       - View receipt
/booking_confirmed.php  - Confirmation details
